# AI-QA-Playbook

This repository documents my learning and practical work in **AI Quality Assurance**, with a focus on testing AI-powered applications beyond traditional functional testing.

The goal is to understand how QA practices need to evolve when application behavior becomes probabilistic, context-aware, and driven by AI models and agents.

---

## 🎯 What This Repository Covers

| Area | Focus |
|---|---|
| LLM Testing | Accuracy, relevance, hallucination, safety, consistency |
| RAG Testing | Retrieval quality, grounding, generation quality |
| AI Agent Testing | Planning, reasoning, tool usage, execution |
| ASR Testing | Speech recognition accuracy and robustness |
| Twilio Testing | Communication, OTP, delivery and failure scenarios |
| Security Testing | Prompt injection, authentication, authorization, SQL injection |
| AI Test Cases | Positive, negative, edge and adversarial scenarios |
| Real-World Scenarios | Practical AI QA problems and defect analysis |
| Automation | Python-based AI/API test automation |
